# 数据结构复习（示例）

> 以下为课堂还原式摘要，非严谨教材。

## 1. 栈与队列

- **栈**：后进先出（LIFO）。典型用途：括号匹配、DFS 手写栈。
- **队列**：先进先出（FIFO）。典型用途：BFS、滑动窗口辅助。

## 2. 哈希表

平均 `O(1)` 查找的依据是：**负载因子**可控且哈希函数近似均匀。

冲突处理简述：

| 策略 | 要点 |
|------|------|
| 链地址法 | 桶内链表/向量 |
| 开放寻址 | 探测序列；删除需惰性标记 |

## 3. 二叉搜索树

中序遍历得到升序序列（在无重复键的简化模型下）。

::: warning 注意
随机 BST 期望高度 `O(log n)`；退化链为 `O(n)`。实用结构常选红黑树、AVL、B 树家族。
:::
