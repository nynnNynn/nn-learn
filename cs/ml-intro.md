# 机器学习入门（示例）

## 监督学习流水线（口头版）

1. **数据**：划分 train / validation / test；泄漏检查。
2. **表示**：特征工程或表征学习。
3. **模型**：线性模型 → 树模型 → 神经网络（按复杂度递进）。
4. **优化**：损失函数 + 正则；学习率与 batch size。
5. **评估**：任务相关指标（准确率、F1、MSE…）。

## 小例子：线性回归

目标：近似 **y ≈ wᵀx + b**（占位记号）。

训练时常用均方误差（写法示意）：

```
L = (1/N) × Σᵢ ( yᵢ − (wᵀxᵢ + b) )²
```

（正文仅为排版演示，不涉及推导细节。）
