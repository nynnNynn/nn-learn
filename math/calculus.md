# 微积分要点（示例）

## 极限与连续

函数 **f** 在 **a** 连续：**三点合一**

```
lim(x→a) f(x) = f(a)
```

（三段定义：极限存在、函数值存在、二者相等。）

## 导数

几何意义：切线斜率。线性近似：

```
f(a+h) ≈ f(a) + f′(a)·h    （h → 0）
```

## 积分与 FTC（占位陈述）

若 **F′ = f** 且在区间上满足常用条件，则

```
∫ₐᵇ f(x) dx = F(b) − F(a)
```
